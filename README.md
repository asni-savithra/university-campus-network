# University Campus Network Design

## Project Overview
This project demonstrates the design and configuration of a university campus network using Cisco Packet Tracer.

## Technologies Used
- Cisco Packet Tracer
- VLANs and Inter-VLAN Routing
- OSPF Routing
- DHCP
- DNS
- HTTP Web Server
- IP Addressing and Subnetting

## Network VLANs

| VLAN | Department | Network |
|---|---|---|
| 10 | Administration | 192.168.10.0/24 |
| 20 | Lecturers | 192.168.20.0/24 |
| 30 | Computer Lab | 192.168.30.0/24 |
| 40 | Library | 192.168.40.0/24 |
| 50 | Servers | 192.168.50.0/24 |

## Network Devices
- 3 Routers
- 6 Switches
- 12 PCs
- 2 Servers
- 1 Printer

## Services
- DHCP for automatic IP configuration
- DNS for local name resolution
- HTTP for hosting the campus website
- OSPF for routing between routers

## Testing
Connectivity and web access were tested in Cisco Packet Tracer. Further testing should confirm DHCP, DNS, and all VLAN-to-VLAN connectivity.
